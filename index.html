AI verification · Featured write-up

Probative: An LLM Triage Pipeline That Doesn't Trust Its Own Model

structuredfabricatedcaughtmeasured

A local research prototype, not a deployed tool: can an AI's own security findings actually be checked, instead of just taken on faith? Sigma rules decide which alerts are worth looking at and set the severity before any model gets involved. One local model writes up the evidence; a second, kept blind to the first one's reasoning, judges whether that write-up actually holds up. The check proved its worth the day it broke: constrained decoding knocked out the investigator's evidence gathering, the model started inventing whole incidents on hosts that don't exist, and the deterministic check caught every one of them.

AI safety · Lab deployment · Write-up

grounding-verifier: A Safety Gate for AI That Takes Action

claimedgroundedauthorizedacts

A cheap local model triages the alert, then something other than a model checks its work. Every claim gets grounded against the field that actually proves it, and only then does the gate decide: authorize, deny, or hold for a human. It runs against a lab Azure Sentinel tenant, reversible actions only, with local inference at zero token cost. No model inside the gate itself, so the decision cannot be hallucinated.
