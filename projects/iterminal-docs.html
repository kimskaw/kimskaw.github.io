Overview

What is iTerminal?

iTerminal is a custom iOS home screen widget that mimics a Unix terminal interface. It's built using Scriptable, a free iOS app that lets you write JavaScript to create widgets.

This is a modification of the original iTermWidget by yaylinda. The original widget provided the terminal aesthetic, calendar events, weather, and device stats. This version adds live Bitcoin prices in AUD, a parked car location tracker via CarPlay automation, switches weather to metric units, and fixes compatibility with the current OpenWeatherMap API.

Every piece of data is fetched live: weather from OpenWeatherMap, Bitcoin prices from CoinGecko, calendar events from your iPhone, and your parked car location via a CarPlay automation.

Under the Hood

Challenges & What Was Fixed

The original iTermWidget wasn't working out of the box: several real-world issues had to be diagnosed and resolved to get it running.

🔧

OpenWeatherMap API Deprecation

The original script used the onecall endpoint (/data/2.5/onecall), a single request that returned current weather, hourly and daily forecasts all at once. In 2022, OpenWeatherMap moved this endpoint from the free tier to a paid subscription called One Call API 3.0. Old free-tier API keys stopped receiving data from it silently.

The original script then tried to read data.current.sunset from the empty response, causing the crash:

TypeError: undefined is not an object (evaluating 'data.current.sunset')

The fix: Replaced the deprecated onecall request with two separate free endpoints that are still active: /data/2.5/weather for current conditions and /data/2.5/forecast for the daily high/low. This required refactoring how weather data was parsed and assembled.

📦

Missing Cache Module

The original script relied on importModule('Cache'), a separate Scriptable script that had to be installed alongside it. Without it the widget crashed immediately:

Error: No file to import at Cache

Since Scriptable has no package manager, the Cache class was written from scratch and inlined directly at the top of the main script. It uses Scriptable's built-in FileManager API to read and write JSON files to the device's local storage, no external dependencies needed. The result is one completely self-contained script with zero imports.

Inlined Cache class: replaces importModule('Cache') 
class Cache {
  constructor(name) {
    this.fm = FileManager.local();
    this.dir = this.fm.joinPath(this.fm.documentsDirectory(), name);
    if (!this.fm.fileExists(this.dir)) {
      this.fm.createDirectory(this.dir);
    }
  }

  write(key, value) {
    const path = this.fm.joinPath(this.dir, key.replace(/[^a-z0-9_-]/gi, '_'));
    this.fm.writeString(path, JSON.stringify(value));
  }

  read(key, maxAgeMinutes) {
    const path = this.fm.joinPath(this.dir, key.replace(/[^a-z0-9_-]/gi, '_'));
    if (!this.fm.fileExists(path)) return null;
    if (maxAgeMinutes) {
      const modified = this.fm.modificationDate(path);
      const ageMinutes = (new Date() - modified) / 1000 / 60;
      if (ageMinutes > maxAgeMinutes) return null;
    }
    try {
      return JSON.parse(this.fm.readString(path));
    } catch { return null; }
  }
}
🚗

Parked Car Tracker via CarPlay Automation

There's no native iOS API to read "last parked location" from a widget. The solution was to use an iOS Shortcuts automation triggered on CarPlay disconnect: it silently runs a small Scriptable script that writes the current GPS coordinates to a local JSON file. The widget then reads that file and reverse geocodes the coordinates into a street address. No third-party service or API key required.

🗂️

Stale Cache Causing Invisible Failures

During development, the widget was caching API responses from when the API key was still set to TODO. Even after updating the key, the widget kept returning blank weather data because it was reading from the cache rather than making fresh requests. The fix was adding a clearAll() method to the Cache class that wipes the cache directory on each run during setup, ensuring fresh data is always fetched.

Step 1

Install Scriptable

Scriptable is a free app on the iOS App Store that lets you run JavaScript to create widgets and automations.

1

Download Scriptable

Search for Scriptable on the App Store and install it. It's free with no in-app purchases required for this widget.

2

Grant permissions

Open Scriptable, then go to iPhone Settings → Scriptable → Location and set it to While Using the App. Also grant Calendar access when prompted.

Step 2

Get an OpenWeatherMap API Key

The widget uses the free OpenWeatherMap API to fetch current weather and forecasts. No credit card is required.

1

Create a free account

Go to openweathermap.org and sign up for a free account.

2

Copy your API key

After signing in, go to API Keys in your profile. Copy the default key shown there. It's a 32-character string.

3

Wait for activation

New keys can take up to 2 hours to activate. If weather shows as Unavailable shortly after setup, wait and try again.

Step 3

Add the Main Widget Script

Create a new script in Scriptable and paste in the widget code.

1

Create a new script

Open Scriptable, tap + in the top right to create a new script. Name it iTerminal.

2

Paste the code

Copy the full script from below and paste it into the editor.

3

Fill in your values

At the top of the script, update these constants:

Configuration: update these values 
// Your first name, shown in the terminal prompt
const NAME = 'KIM';

// From openweathermap.org → API Keys (free account)
const WEATHER_API_KEY = 'your_32_char_key_here';

// Exact calendar names as shown in Calendar app → Calendars
const WORK_CALENDAR_NAME = 'Work';
const PERSONAL_CALENDAR_NAME = 'Personal';
Finding your calendar names: Open the Calendar app → tap Calendars at the bottom → the names listed there are what to use. Capitalisation matters.
Step 4

Set Up the Parked Car Automation

This two-part setup saves your car's location automatically whenever you disconnect from CarPlay.

1

Create the SavedParking script

In Scriptable, create a new script named exactly SavedParking and paste in this code:

SavedParking.js: save as a separate Scriptable script 
const location = await Location.current();
const fm = FileManager.local();
const path = fm.joinPath(fm.documentsDirectory(), 'parked.json');
fm.writeString(path, JSON.stringify(location));
Script.complete();
2

Create the Shortcuts automation

Open the Shortcuts app → Automation tab → tap + → New Automation.

3

Set the trigger

Scroll down and choose CarPlay as the trigger, then select Disconnects.

4

Add the action

Tap Add Action, search for Scriptable, choose Run Script, and select SavedParking.

5

Disable confirmation

Set Automation to Run Immediately and turn off Notify When Run so it runs silently in the background.

Note: The widget will show "Not saved yet" until you disconnect from CarPlay for the first time. After that it updates automatically on every disconnect.
Step 5

Add the Widget to Your Home Screen

1

Long-press your home screen

Enter jiggle mode, then tap the + button in the top left corner.

2

Find Scriptable

Search for Scriptable in the widget picker. Choose the medium size widget for best results.

3

Select the script

Tap the widget to configure it. Set the Script field to iTerminal and leave the other fields empty.

Troubleshooting

Common Issues

Weather shows 0° or Unavailable

Your API key may not be activated yet (takes up to 2 hours after signup), or the key was entered incorrectly. Verify it's exactly 32 characters and try opening the weather URL directly in Safari to check the response.

Calendar shows "No upcoming events" when there are events

The calendar name doesn't match exactly. Open Calendar app → tap Calendars at the bottom → copy the name exactly including capitalisation. Email addresses won't work as names.

Car shows "Not saved yet"

The SavedParking automation hasn't run yet. Disconnect from CarPlay once and it will save. If it still doesn't work, check that Scriptable has Location permission set to "While Using".

Widget shows stale data

iOS controls widget refresh rates and may throttle updates. Opening the Scriptable script directly and running it will force a fresh fetch. The widget auto-refreshes roughly every 15–30 minutes.

Bitcoin shows Unavailable

CoinGecko's free API has rate limits. If you run the widget too frequently it may temporarily block requests. Wait a few minutes and refresh.
